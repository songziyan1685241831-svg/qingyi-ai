# 小智AI陪伴机器人 — 执行计划（Roadmap）

> 创建日期：2026-07-23 | **更新日期：2026-07-23**
> 这是一个长周期计划文档，记录每个阶段的目标、任务、完成情况

---

## 🎯 总目标

> 从零开始，亲手做一个会对话、会表情、能动、能接入 AI 大模型的桌面陪伴机器人。
>
> **自定义路线：** 硬件用 xiaozhi-esp32 方案 + **自建 Cloudflare Workers 服务端** + 多模型 LLM（Claude/DeepSeek）+ 火山引擎语音，完全掌控自家的 AI。
>
> 最终形态：一台完全属于你自己的、不可替代的 AI 陪伴机器人。

---

## Phase 0.5：自建云端服务器 ☁️（第1-2周）【自定义核心路线】

**目标：** 部署 Cloudflare Workers 服务端，对接火山引擎语音 + 多模型 LLM，建好配置页面

> 这个阶段不依赖硬件，纯云端操作。即使硬件还没到，也可以先做。

### 前置条件
- [ ] Cloudflare 账号（已有，已绑卡）
- [ ] 已开通 **Workers Paid 计划**（$5/月，免费计划 CPU 不够处理实时语音）
- [ ] 火山引擎账号（已有，已验证）
- [ ] 从火山引擎控制台获取 AppID + Access Token（语音服务）

### 任务清单

#### 0.5.1 Worker 部署基础
- [ ] 安装 Node.js + wrangler CLI
- [ ] `wrangler login` 登录 Cloudflare
- [ ] 创建 Worker 项目
- [ ] 创建 KV 命名空间（存配置）
- [ ] `wrangler deploy` 部署 Hello World

#### 0.5.2 实现 WebSocket 网关
- [ ] WebSocket 握手 + 接收 ESP32 连接
- [ ] 实现 xiaozhi 协议 hello 消息
- [ ] 会话管理（session_id、状态机）
- [ ] 超时/断线重连处理

#### 0.5.3 对接火山引擎 ASR
- [ ] 在 Worker 端连接火山引擎 WebSocket 做语音识别
- [ ] 流式转发：ESP32 Opus 音频 → Worker → 火山引擎
- [ ] 返回识别结果（stt 消息）给 ESP32

#### 0.5.4 对接 LLM（多模型 fallback）
- [ ] 实现 Claude API 调用
- [ ] 实现 DeepSeek API 调用（兜底）
- [ ] 实现 fallback 逻辑（Claude 失败 → DeepSeek）
- [ ] 支持系统 Prompt（角色设定）
- [ ] 支持携带对话历史

#### 0.5.5 对接火山引擎 TTS
- [ ] 在 Worker 端连接火山引擎 TTS WebSocket
- [ ] 流式转发：LLM 回复 → 火山引擎 TTS → Opus 音频 → ESP32
- [ ] 发送 tts start/stop 状态消息

#### 0.5.6 配置页面
- [ ] 设计类 cc-switch 风格的控制台（HTML/CSS/JS）
- [ ] LLM 设置：Claude Key + DeepSeek Key + 模型选择 + fallback 顺序
- [ ] 语音设置：火山引擎 AppID + Token + TTS 音色选择
- [ ] 角色设定：名字 + 系统 Prompt 编辑器
- [ ] 设备状态监控（在线/对话次数/最后在线时间）
- [ ] KV 存取配置

#### 0.5.7 Worker 完整集成测试
- [ ] 用 wscat 或 Postman WebSocket 客户端模拟 ESP32
- [ ] 测试全链路：音频 → ASR → LLM → TTS → 音频
- [ ] 测试 fallback 逻辑（断掉 Claude Key 看 DeepSeek 能否接管）
- [ ] 测试配置页保存/读取

### 文件参考
- [ ] `03-自定义AI机器人-架构方案.md` — 完整架构说明
- [ ] `05-部署指南.md` — 详细部署步骤

### 验收标准
- ✅ Worker 能接收 WebSocket 连接并响应 hello
- ✅ ASR 能识别语音（测试工具发送音频，收到文字）
- ✅ LLM 能回复（Claude 为主，DeepSeek 兜底）
- ✅ TTS 能合成语音返回
- ✅ 配置页面能正常打开、保存配置
- ✅ 全链路测试通过

## Phase 1：先跑起来 🏃（第2-3周）

**目标（自定义路线）：** 编译自定义固件（指向你的 Worker），烧录进 ESP32，让机器人走你自己的服务器

### 任务清单

- [ ] 1.1 安装 ESP-IDF 开发环境（VSCode + IDF 插件 5.4+）
- [ ] 1.2 克隆 xiaozhi-esp32 源码
  ```
  git clone https://github.com/78/xiaozhi-esp32
  ```
- [ ] 1.3 修改服务器地址
  - 找到 `main/protocols/websocket_protocol.cc`
  - 修改默认 WebSocket URL 为你的 Worker 地址
  - 或通过 Kconfig 配置项设置

- [ ] 1.4 编译固件
  - 选择对应开发板配置
  - `idf.py build`
  
- [ ] 1.5 烧录固件
  - `idf.py -p COM端口 flash monitor`
  - 或用 Flash Download Tool

- [ ] 1.6 首次连接
  - 上电 → 配网（连 Wi-Fi）
  - 设备连接你的 Worker
  - Worker 配置页看到设备上线

- [ ] 1.7 体验你的专属 AI 对话
  - 唤醒对话
  - 走你自己的 Worker → Claude/DeepSeek 链路
  - 确认配置页修改 Prompt 后生效

- [ ] 1.8 体验配置页
  - 切换到 DeepSeek 模型
  - 修改角色设定
  - 看机器人反应变化

### 验收标准
- ✅ ESP32 连上你的 Cloudflare Worker
- ✅ 对话走通（语音 → ASR → LLM → TTS → 播放）
- ✅ 配置页修改 LLM 后生效
- ✅ 配置页修改角色后生效`

## Phase 2：基础学习 📚（第2-4周）

**目标：** 打下C语言和单片机基础，能看懂和修改简单代码

### 2.1 C语言基础

**没必要学完整C语言！** 只需掌握：

| 知识点 | 掌握标准 | 预计时间 |
|--------|---------|---------|
| 变量与数据类型 | int/char/float/数组 | 2小时 |
| 条件判断 | if/else/switch | 1小时 |
| 循环 | for/while | 1小时 |
| 函数 | 定义/调用/传参/返回值 | 1小时 |
| 指针 | 指针基础、取地址、解引用 | 2小时 |
| 结构体 | struct 定义和使用 | 1小时 |
| 头文件 | #include、宏定义 | 0.5小时 |

**学习资源：**
- 推荐B站搜索「C语言速成」「C语言入门」
- 或「菜鸟教程 C语言」在线教程
- 不要看书！**视频 + 自己敲** 比看书快10倍

### 2.2 电路基础

| 知识点 | 掌握标准 |
|--------|---------|
| 欧姆定律 | U=IR，会算限流电阻 |
| 上拉/下拉电阻 | 10kΩ 上拉 |
| IO口电平 | 3.3V 逻辑 |
| 通信协议 | 知道 I2C/SPI/I2S/UART 各是什么、何时用 |

### 2.3 ESP-IDF 环境搭建

- [ ] 安装 VSCode
- [ ] 安装 ESP-IDF 插件
- [ ] 设置 SDK 版本 5.4+
- [ ] 能编译示例工程（hello_world）
- [ ] 能烧录并看到串口输出

### 2.4 点灯实验

**这是单片机的「Hello World」！**

- [ ] GPIO 输出：让 LED 亮灭
- [ ] PWM：呼吸灯效果
- [ ] GPIO 输入：按键控制 LED
- [ ] 看文档了解小智项目的 gpio 配置

### 验收标准
- ✅ 能写简单的 C 程序（循环、数组、函数调用）
- ✅ ESP-IDF 环境能编译烧录
- ✅ 开发板上的灯能按程序亮灭
- ✅ 能用串口打印调试信息

## Phase 3：外设驱动 🛠️（第4-6周）

**目标：** 掌握常用外设驱动，能读懂小智源码的硬件层

### 3.1 I2C 驱动 OLED 屏

- [ ] 了解 I2C 协议原理（SCL/SDA/地址）
- [ ] 接线：VCC→3.3V, GND→GND, SCL→GPIO, SDA→GPIO
- [ ] 运行 OLED 显示 Demo
- [ ] 显示中文、画图
- [ ] **分析小智项目的 LCD 驱动代码**

### 3.2 I2S 麦克风（录音）

- [ ] 了解 I2S 协议原理（BCLK/WS/DIN/DOUT）
- [ ] 接线 INMP441
- [ ] 运行录音 Demo
- [ ] 验证能录到音频数据

### 3.3 I2S 功放+喇叭（放音）

- [ ] 接线 MAX98357
- [ ] 运行播放 Demo
- [ ] 播放 WAV 文件
- [ ] **分析小智项目的音频管道**

### 3.4 理解小智音频流

```
麦克风 → I2S IN → OPUS编码 → 网络发送 → 云端ASR
                                                        → LLM → TTS
喇叭 ← I2S OUT ← OPUS解码 ← 网络接收 ← 云端TTS
```

- [ ] 能看懂代码中的音频缓冲区和处理流程
- [ ] 知道 i2s_read() 和 i2s_write() 在哪调用

### 验收标准
- ✅ 能单独驱动屏幕并显示内容
- ✅ 能录音并播放简单的音频
- ✅ 能大致看懂小智项目的 main 函数流程
