## 一、项目概述

### 1.1 这是什么项目？

基于 **ESP32 芯片** 的开源 AI 语音对话机器人。使用大语言模型（LLM）作为「大脑」，通过语音与用户交流，屏幕显示表情，支持 MCP 协议扩展控制智能设备。

### 1.2 "小智AI"是谁开源的？

由**虾哥**（GitHub 用户 `78`）在 GitHub 开源，MIT 协议，可免费使用、修改、商用。

- 主仓库：https://github.com/78/xiaozhi-esp32
- 项目名称：xiaozhi-esp32
- 协议：MIT（完全开源自由）
- GitHub Stars：超过 10k+
- QQ交流群：1011329060

### 1.3 核心工作流程

```
用户说话 → 麦克风拾音
         → 离线语音唤醒（ESP-SR）
         → OPUS 音频编码
         → ASR 语音识别（云端）
         → LLM 大模型理解与生成（云端）
         → TTS 语音合成（云端）
         → OPUS 解码 → 喇叭播放
         → 屏幕显示表情
         
整段延迟约 0.5-2 秒，日常对话基本无感
```

### 1.4 已实现功能

- ✅ Wi-Fi 连接 / ML307 Cat.1 4G 联网
- ✅ 离线语音唤醒（默认「你好小智」）
- ✅ 流式语音对话（ASR + LLM + TTS）
- ✅ OPUS 音频编解码（高压缩低延迟）
- ✅ OLED / LCD 显示屏表情
- ✅ 声纹识别（识别谁在说话）
- ✅ 电量显示与电源管理
- ✅ 支持中文、英文、日文
- ✅ 支持 MCP 协议设备控制（灯光、电机、GPIO等）
- ✅ 云端 MCP 扩展（智能家居、PC操作、搜索、邮件）
- ✅ 自定义唤醒词、字体、表情、聊天背景（网页在线改）
- ✅ 支持 ESP32-C3 / S3 / P4 芯片

## 二、硬件知识

### 2.1 主控芯片选型

芯片选型参考：

| 芯片 | 推荐度 | 说明 |
|------|--------|------|
| **ESP32-S3** | ⭐⭐⭐⭐⭐ | **首选**！性能足够，带 AI 加速指令集，支持 OTA |
| ESP32-C3 | ⭐⭐⭐ | 够用但性能略低，成本更低 |
| ESP32-P4 | ⭐⭐⭐⭐ | 最新最强，但目前支持相对少 |

### 2.2 外设清单总表

| 类别 | 型号 | 通信接口 | 单价(约) | 说明 |
|------|------|---------|---------|------|
| **主控** | ESP32-S3 开发板 | USB | 50-150 | 推荐立创实战派或BOX3 |
| **麦克风** | INMP441 | I2S | 5 | 数字 MEMS 麦克风 |
| **功放** | MAX98357 | I2S | 8 | 3W D类功放模块 |
| **喇叭** | 3W 8Ω 小喇叭 | 模拟 | 8 | 选带腔体的 |
| **屏幕** | SSD1306 0.96寸 | I2C | 10 | OLED 128x64 |
| **屏幕(升级)** | ST7789 1.54寸 | SPI | 20 | TFT 彩屏 |
| **电源** | 18650 电池 | 锂电池 | 15 | 配充放电模块 |
| **按键** | 轻触开关 | GPIO | 1 | 配 10kΩ 上拉电阻 |
| **LED** | 普通 LED | GPIO | 0.5 | 串 220Ω 电阻 |

### 2.3 成品开发板推荐

**适合新手的成品板（到手即用，无需焊接）：**

1. **立创·实战派 ESP32-S3** ~60元

   - 带麦克风 + 喇叭接口

## 三、软件环境搭建

### 3.1 固件烧录（免编译方案）

**适合零基础，只需 30 分钟就能跑起来：**

1. **下载固件**：从 GitHub Releases 下载 `xiaozhi-esp32` 预编译固件
2. **安装烧录工具**：
   - 推荐：ESP32 Flash Download Tool（乐鑫官方）
   - 或使用 esptool.py（Python 环境）
3. **连接硬件**：Type-C 数据线连电脑
4. **烧录**：选对 COM 口和芯片型号 → 擦除 → 烧录
5. **首次开机**：
   - 设备启动 → 屏幕显示配网二维码
   - 手机微信扫码 → 输入 Wi-Fi 密码
   - 注册 xiaozhi.me 账号
   - 开始对话！

**详细教程：**
- B站视频：https://www.bilibili.com/video/BV1XnmFYLEJN/
- 飞书文档：https://ccnphfhqs21z.feishu.cn/wiki/Zpz4wXBtdimBrLk25WdcXzxcnNS

### 3.2 开发环境搭建（需编程）

**当你准备修改代码时搭建：**

1. **安装 VSCode** + ESP-IDF 插件（或使用 Cursor）
2. **安装 ESP-IDF SDK** 5.4 或以上版本
3. **克隆代码**：
   ```
   git clone https://github.com/78/xiaozhi-esp32
   ```
4. **下载依赖**：ESP-IDF 会自动下载组件
5. **编译**：`idf.py build`
6. **烧录**：`idf.py -p COM端口 flash monitor`

> ⚠️ Linux 编译比 Windows 快很多，可用 WSL2

### 3.3 开发环境组件

```
xiaozhi-esp32/
├── main/              # 主程序代码
├── components/        # 组件（驱动、协议等）
├── partitions/        # 分区表配置

├── sdkconfig          # ESP-IDF 配置
├── Makefile           # 编译文件

```

## 四、大模型配置

## 六、常见问题

### Q：零基础能做吗？

能。这个项目开发设计就考虑了新手：
1. 直接烧录固件无需写代码
2. B站有完整视频教程
3. Q群有人帮忙解决问题
4. 社区活跃，遇到问题有人回答

### Q：成本最低多少？

最低约 **60-100 元**（买块 ESP32-S3 开发板），使用 xiaozhi.me 免费服务器额度。

### Q：和抖音小智AI一样吗？

开源版「xiaozhi-esp32」就是小智AI的底层方案。抖音上的小智AI桌面机器人很多就是这个项目或者基于它魔改的。

### Q：需要焊接吗？

买成品开发板不需要焊。如果用面包板接外设，直接杜邦线插接就行。

### Q：能自己做 PCB 吗？

可以。立创EDA 免费画图 + 立创打样（~20元/5片，包邮）。项目有不少开源的 PCB 设计可以参考。
