## 第1天 2026-07-23：项目启动

### 初次接触
想做抖音小智AI那种陪伴机器人，发现底层就是 GitHub 开源项目 `xiaozhi-esp32`（MIT协议，虾哥开源）。

### 转折：不做小智，做自己的
不要成品，要基于 xiaozhi-esp32 硬件 + **自建服务器** + 多模型 LLM，做完全属于自己的 AI 机器人。

### Cloudflare → 国内云服务器
Cloudflare Workers 需要国际信用卡（¥36/月），国内卡买不了。  
**改为腾讯云轻量服务器（¥34/月），支付宝直接付。**

### 确定服务栈

| 服务 | 用途 | 费用 |
|------|------|------|
| 腾讯云轻量服务器 | 跑服务端 | ¥34/月 |
| 火山引擎 ASR | 语音识别 | 免费额度 |
| Edge TTS | 语音合成 | 免费 |
| DeepSeek API | 大模型 | 极低 ~¥2-5/月 |

## v5.0：多页菜单

**核心改动：**

1. **菜单式导航** — 主界面变成卡片菜单，点击进入子页面，不再所有东西挤一起
2. **多LLM供应商** — 可添加/删除任意数量，每个独立配置：
   - 名称 / API地址（完全自定义） / API Key / 模型列表 / 选用模型 / 优先级 / 请求头
   - 支持 DeepSeek / Claude / OpenAI / 自定义
   - 自动按优先级 fallback（一个不行换下一个）
3. **多MCP服务器** — 可添加/删除，每个独立配置名称/地址/Token
4. **API Key明文显示** — 不再缩成几个字符
5. **点击保存全部生效**

### v5.1~5.2：体验优化

- 按 `ESC` 直接返回主菜单
- 右上角 `?` 按钮 → 使用说明弹窗

## 关于联网的说明

使用 xiaozhi-esp32 开源固件自带的配网功能：
- 首次开机屏幕显示二维码
- 手机微信/浏览器扫码 → 选WiFi输密码
- 连上网后自动连接 `ws://服务器IP:8001`
- **不需要6位激活码，不需要绑定小智官方**
- 没有屏幕显示也不怕：可在固件中写死 WiFi 信息
