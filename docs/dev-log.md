架构思路：xiaozhi-esp32 硬件 + Cloudflare Workers 服务端 + 多模型LLM + 火山引擎语音

### 最终服务端文件
完整 Python 服务端代码，包含：
- WebSocket 网关（端口8001，与ESP32通信）
- 火山引擎ASR桥接（语音识别转文字）
- DeepSeek LLM 调用（大模型对话）
- Edge TTS 语音合成（10+种音色，可调语速）
- 网页配置页面（端口8000）

### 配置页面上线
访问 `http://你的服务器IP:8000/config`（配置页面）
- 可改机器人名字
- 可改系统Prompt（角色性格）
- 可改TTS音色（10+种选择）
- 可调速语

### 关于硬件
**Q：我没烙铁，要免焊方案**
